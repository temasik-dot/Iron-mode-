# IRON MODE — Android starter

Тёмное Android-приложение на Kotlin + Jetpack Compose.

## Что уже есть
- Главный экран с расписанием: среда, пятница, воскресенье.
- Твоя текущая программа и упражнения.
- Отметка выполненных упражнений.
- Вкладка программы с переключением дней.
- Простой экран прогресса.
- Тёмная тема с оранжевым акцентом.

## Как открыть и собрать
1. Установи Android Studio (версия с поддержкой Android Gradle Plugin 8.7+).
2. Распакуй архив.
3. В Android Studio выбери **Open** и укажи папку `iron_mode_android`.
4. Дождись Gradle Sync.
5. Подключи Android-телефон с USB debugging или запусти эмулятор.
6. Нажми Run ▶.

Чтобы получить APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Важно
Это стартовая версия проекта, а не готовый опубликованный APK. Отметки упражнений пока хранятся только в памяти текущего запуска; следующим этапом добавим постоянное локальное хранение, ввод рабочих весов, таймер отдыха, редактирование программ и историю тренировок.
