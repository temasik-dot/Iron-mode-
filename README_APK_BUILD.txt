IRON MODE — сборка APK через GitHub Actions

1. Загрузите содержимое этой папки в корень существующего GitHub-репозитория temasik-dot/iron-mode, сохранив структуру папок.
2. В GitHub откройте вкладку Actions.
3. Выберите workflow “Build IRON MODE APK”.
4. Нажмите “Run workflow” → “Run workflow”.
5. Дождитесь зелёной галочки.
6. Откройте завершённый запуск и скачайте artifact “IRON-MODE-debug-APK”.
7. Распакуйте скачанный artifact ZIP на телефоне. Установите APK из него, разрешив установку из этого источника, если Android спросит.

Примечание: это debug APK для личной установки и тестирования, не подписанный релиз для Google Play.
