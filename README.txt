IRON MODE — мобильное приложение (PWA)

В папке находится веб-приложение с манифестом, иконками и офлайн-кешем.

Для установки на Android:
1. Размести ВСЕ файлы и папку icons на HTTPS-хостинге (например, GitHub Pages или Netlify).
2. Открой опубликованный HTTPS-адрес в Chrome на Android.
3. Нажми меню ⋮ → «Установить приложение» или «Добавить на главный экран».
4. После первой загрузки приложение сможет открываться офлайн.

Важно: открыть index.html локально можно для теста, но установка PWA и Service Worker требуют HTTPS (или localhost). Прогресс хранится локально в браузере телефона. Используй «Экспортировать мои данные» для резервной копии.
